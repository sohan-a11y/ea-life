HOW THIS DEMO WORKS

Each organism has mutable preference weights, a small action-value table, energy and a novelty record. Reproduction happens under explicit simulation rules. “Research topics” are built-in local labels, not internet searches.

◆No backend, account tokens, third-party API calls, or network requests are used by this demo.
