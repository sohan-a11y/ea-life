Experiment integrity

EA-Life is a bounded artificial-life model. The simulator has no network interface; a separate broker accepts fixed topic IDs and returns short snippets. The dashboard receives public observations, not private genomes, Q tables or episodic memories. Broker allowlisting is application-level and should be backed by host egress controls for a stronger threat model.
